# 👋 안녕하세요, 안선효입니다!

창원대학교에서 컴퓨터공학을 전공하며 다양한 프로젝트를 통해
**웹 개발부터 시스템, 데이터 통신까지 직접 구현하고 경험하고 있습니다.**

## 🧑‍💻 About Me

* 🎓 컴퓨터공학 전공
* 💻 다양한 프로젝트를 직접 설계하고 구현하는 것을 좋아합니다.
* 🚀 프로젝트를 진행하며 새로운 기술을 배우는 과정을 중요하게 생각합니다.
* 🌱 웹 개발, 백엔드, 소프트웨어 설계 및 시스템에 관심이 있습니다.
* 🔧 기능 구현뿐만 아니라 문제를 해결하고 개선하는 과정을 기록하려고 합니다.

🔧 단순히 기능을 구현하는 것에 그치지 않고, **협업과 유지보수까지 고려한 개발 과정**을 경험하는 것을 목표로 하고 있습니다.

> [!IMPORTANT]
> ### 💬 Development Philosophy
>
> 부트캠프 경험을 바탕으로 **문제 해결과 직접 구현하는 코딩 역량**을 쌓았습니다.
> 현재는 변화하는 개발 환경에 맞춰 **Codex를 개발 도구로 적극 활용**하는
> **WorkFlow 기반의 개발 방식**을 경험하며 체득하고 있습니다.
